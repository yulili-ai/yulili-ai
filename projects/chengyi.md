# Chengyi · 非遗 AI 共创体验

**Interactive prototype · 在线版使用本地规则**

## 场景

把陶瓷创作做成可以探索和参与的数字体验：从山河地图与工艺叙事进入工作台，选择泥料、调整器形、施釉、入窑，再导出作品。

## 交互思路

把对话和直接操作放进同一创作流程。拖动塑形会修改三维网格，创作过程支持撤销、重做和本机草稿。希望用户既能表达想法，也能看清每次操作如何改变作品。

## 当前边界

公开的 GitHub Pages 版本为静态体验，提供场景、陶艺操作与本地关键词规则；不代表在线接通真实大模型、语音或后台同步。仓库另有 Python 后台与模型、语音接入说明，需要单独配置运行。本页依据公开仓库说明整理，未重新验证完整流程。

当前开放陶瓷；其他器物只作预览。配图是交互示意，实际界面请看在线体验。
